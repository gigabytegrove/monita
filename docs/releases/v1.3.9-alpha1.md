# Monita v1.3.9-alpha1

**Status:** Alpha prerelease  
**Release date:** 2026-10-05

Monita 1.3.9-alpha1 is the first published alpha of the redesigned Monita Web UI.

## Web UI redesign

- Introduces the first alpha iteration of the redesigned Monita Web interface.
- Restores a functional **Light / Dark / System** appearance selector.
- Persists the selected appearance per browser.
- Correctly follows the operating-system theme when **System** is selected.
- Rebalances the visual system around Monita's blue-and-gray identity.
- Removes the overly purple/indigo cast from the primary interface palette.
- Reduces excessive rounding across controls, menus, inputs, chips, and dialogs.
- Refreshes Web/PWA cache identifiers so updated branding and styling load cleanly after upgrading.

## Release channel

This build is published as an **Alpha** prerelease and should appear to Monita 1.3.8 installations that allow prerelease updates.

The stable line remains **1.3.8** until the 1.3.9 redesign completes Alpha, Beta, and RC validation.
