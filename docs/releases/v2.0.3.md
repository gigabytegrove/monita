# Monita v2.0.3 — Critical October 2026 Dependency Maintenance

## Security advisories addressed

The Monita 2.0.2 security scan identified three **HIGH** findings in its bundled JavaScript dependencies. This release updates the resolved, checksum-locked packages rather than masking or suppressing the security scanner.

- **CVE-2026-111755 and CVE-2026-111756** — `follow-redirects` 1.16.0 → **1.16.1**; information-disclosure issues.
- **CVE-2026-112942** — `vite` 8.1.2 → **8.1.6**; command-injection issue in launch-editor middleware.
- Accompanying bundler dependencies — `rolldown` 1.1.3 → **1.1.5**, updated matching native binding packages, and `@oxc-project/types` 0.139.0. Resolved Yarn artifacts retain verified npm-registry integrity checks.

## Security baseline retained

- Native Go server and updater: **Go 1.27.3**, including the October 19 Go crypto/x509 security fix.
- Web build environment: **Node.js 24.22.1**, including the October 21 Node.js fixes.
- No deliberate data/schema changes or loss of notification, chat, channel, identity, or companion features.

## Installation guidance

1. Back up Monita's database, attachments, and persisted configuration.
2. Use the in-app updater once the v2.0.3 release and AMD64/ARM64 packages are published, or upgrade the server image through the normal container deployment.
3. Confirm application health and that your running image/binary was rebuilt from the security-updated release; a source change or an available GitHub release does not itself patch an installed instance.

## Release verification

Publication is subject to passing Go/JavaScript tests, frozen Yarn dependency resolution, Docker/image smoke tests, and the repository/dependency HIGH/CRITICAL security scan. If the scanner finds new advisories, publication should stop until reviewed.
