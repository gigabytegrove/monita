# Monita v2.0.2 — October 2026 Security Update

## Security maintenance

This release rebuilds Monita's Go server/runtime with **Go 1.27.3**, incorporating the October 19, 2026 crypto/x509 security update (CVE-2026-111943). The frontend builder now uses **Node.js 24.22.1**, incorporating the October 21 Node.js security updates.

## Changes

- Rebuild server and self-update runtime binaries using the patched Go compiler and standard library.
- Pin the JavaScript frontend build to patched Node.js 24.22.1.
- Align verification and distribution tooling with the patched toolchains; update golangci-lint to a Go 1.27 compatible release.
- Retain existing authentication, notifications, channels, history, chat, API compatibility, themes and mobile companion contracts. No data migration is intended.

## Upgrading

Back up Monita's database, attachments and persisted configuration before upgrading. Use Monita's built-in updater after the new multiarchitecture release bundles have been published and verified, or replace the server container with the validated new image. Publishing the source alone does not update already-running instances.

## Validation and references

This release requires frontend and Go tests, Linux AMD64/ARM64 artifacts, container smoke checks and release checksum verification. The installed binary must be inspected to confirm the newly compiled Go version; changing the source toolchain alone does not patch a running installation.
