# Monita v1.4.0

Monita 1.4.0 is a complete redesign of the server Web interface.

The release replaces the previous card-heavy, rounded admin presentation with a purpose-built workspace UI. Navigation, dashboard, Channels, Messages, chat, authentication, administration, settings, integrations, plugins, update surfaces, and shared components were all reviewed as part of an exhaustive pass over the entire `ui/` tree.

## Interface direction

- flatter low-radius geometry
- no browser-default blue-link treatment
- transcript-style chat instead of speech bubbles
- notification feed rows instead of floating message cards
- sectioned workspaces instead of repeated bordered cards
- dense tables/lists for administrative workflows
- updated PWA/browser theme identity and cache versioning

Android and Home Assistant interfaces are intentionally unchanged in this release.

The full UI audit inventory is recorded in `ui/UI_REDESIGN_AUDIT.md`.
