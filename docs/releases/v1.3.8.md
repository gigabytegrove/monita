# Monita v1.3.8

**Status:** Stable  
**Release date:** 2026-10-05

Monita 1.3.8 upgrades the in-app updater so future Alpha, Beta, RC, and Stable builds can be discovered, identified, compared, and installed correctly.

## Software Update

- Full prerelease Semantic Versioning support
- Explicit release-channel display
- Alpha, Beta, RC, Stable, and Preview classification
- Correct prerelease ordering
- Prerelease install support in the server update API
- Existing checksum and downloaded-runtime verification retained

This is intentionally a focused updater release. The redesigned Web UI is not included in 1.3.8; it follows as the 1.3.9 alpha series.
