# Monita v1.3.8

**Status:** Stable  
**Release date:** 2026-10-05

Monita 1.3.8 upgrades the in-app updater so Monita can safely discover, display, compare, and install Stable and prerelease builds.

## Software Update

- Full prerelease SemVer support
- Alpha, Beta, RC, Stable, and fallback Preview channel labels
- Correct version ordering across prerelease stages
- Full version strings shown in the updater
- Managed installation of prerelease tags such as `1.3.9-alpha`
- Existing checksum and runtime-binary verification retained

## Upgrade path

1. Update an existing installation to **1.3.8**.
2. The Software Update screen can then offer **1.3.9-alpha** as an Alpha-channel update when published.
3. Users who do not want prerelease UI builds can remain on 1.3.8 Stable.

The large Monita Web UI redesign is intentionally **not** part of this release.
