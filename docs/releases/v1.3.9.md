# Monita v1.3.9

**Status:** Stable  
**Release date:** 2026-10-05

Monita 1.3.9 promotes the redesigned Web UI and selectable update-channel work to the stable release line.

## Web UI

- Redesigned Monita Web interface using the blue-and-gray visual system.
- Working **Light / Dark / System** appearance controls.
- Reduced excessive rounding and removed the overly purple/indigo cast from the interface.

## Settings

- Settings is organized into **Account**, **Notifications**, **Security**, and **Updates** tabs.
- Update controls are isolated in the administrator-only Updates tab.

## Update channels

- Added server-persisted update-channel selection.
- Available channels: **Stable**, **Release Candidate**, **Beta**, **Alpha**, and **Preview / Development**.
- Broader channels include releases from the safer channels beneath them.
- Stable remains the default for existing installations.
- The Software Update page and Dashboard update banner honor the selected channel.
