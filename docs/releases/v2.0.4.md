# Monita v2.0.4 — November 2026 security release

This maintenance release preserves channels, messaging, authentication integrations, server-side storage, PWA assets, and single-container update behavior.

- `github.com/go-jose/go-jose/v4`: 4.1.4 → 4.1.9 (including CVE-2026-116587 and related JWK parsing advisories).
- `golang.org/x/net`: 0.60.0 → 0.62.0 (CVE-2026-78661 and CVE-2026-97045).
- Align `golang.org/x/crypto`, `golang.org/x/sys`, and `golang.org/x/text` to patched transitive constraints.
- Upgrade the Go compiler/build baseline to 1.27.4, including the November 10 security fixes.

The existing release pipeline must complete Go tests, frontend verification, build SBOM, runtime binaries and multiarch GHCR publication before this release is accepted. Retain all existing persistent volumes.
