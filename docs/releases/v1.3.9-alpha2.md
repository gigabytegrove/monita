# Monita v1.3.9-alpha2

**Status:** Alpha prerelease  
**Release date:** 2026-10-05

Monita 1.3.9-alpha2 follows the first redesigned Web UI alpha with a major Settings cleanup and administrator-controlled update channels.

## Settings

- Settings is now organized into **Account**, **Notifications**, **Security**, and **Updates** tabs.
- The long single-page settings layout has been removed.
- Update controls are isolated in a dedicated administrator-only Updates tab.

## Update channels

- Added a server-persisted update channel preference.
- Available channels: **Stable**, **Release Candidate**, **Beta**, **Alpha**, and **Preview / Development**.
- Broader channels include releases from safer channels beneath them.
- Stable remains the default on existing installations.
- Both the Software Update page and Dashboard update banner honor the selected channel.

## Validation

- Added backend tests for channel validation and preference persistence.
- Added UI tests for release filtering by update channel.
