# Monita v1.3.9-alpha

**Status:** Alpha  
**Release date:** 2026-10-05

Monita 1.3.9-alpha is the first hands-on preview of the complete server Web UI/UX redesign.

## Web UI redesign

- New flat, low-radius design system
- Rebuilt workspace dashboard and navigation
- Directory-style Channel management
- Redesigned notification and chat presentation
- Redesigned login and shared page hierarchy
- Consistent redesign across Settings, Administration, Integrations, Automation, Plugins, updates, and supporting dialogs
- Browser/PWA assets re-versioned for the alpha build
- Exhaustive review of all 116 files under `ui/`

## Updater compatibility

Monita 1.3.9-alpha retains the updater infrastructure introduced in **1.3.8**:

- full prerelease SemVer handling
- Alpha, Beta, RC, Stable, and Preview channel labels
- prerelease installation support
- checksum and runtime-version verification

## Scope

This release changes the **Monita server Web UI only**. Monita for Android and Monita for Home Assistant are not part of this redesign.

This build is intentionally marked Alpha so the interface can be reviewed in real use before the design is treated as final.
